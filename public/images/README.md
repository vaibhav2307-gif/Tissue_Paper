# Image replacement guide

Add real, owned/licensed business photography here and keep these filenames predictable:

- `hero-factory.jpg` — hero manufacturing image
- `factory-01.jpg` — factory exterior/interior
- `production-01.jpg` — tissue production machinery
- `production-02.jpg` — converting process
- `packaging-01.jpg` — finished packaging
- `warehouse-01.jpg` — warehouse/stock
- `dispatch-01.jpg` — dispatch/logistics
- `product-toilet.jpg`
- `product-facial.jpg`
- `product-napkin.jpg`
- `product-kitchen.jpg`
- `product-hand-towel.jpg`
- `product-custom.jpg`

The current website intentionally uses labelled visual placeholders until real images are supplied. Do not add copyrighted images without permission.
